# Robovan商业模式分析模型

## 项目简介
这是一个用于分析自动驾驶货运车（Robovan）商业模式的量化分析工具。通过Python代码自动生成Excel分析模型，对比Robovan与传统货运方式的经济效益。

## 核心分析维度

### 1. 能赚多少钱？（收入模型）
- Robovan运营收入
- 不同场景下的定价策略
- 规模化收入预测

### 2. 要花多少钱？（成本结构）
- 初始投资成本（车辆、技术、基础设施）
- 运营成本（维护、能源、保险、管理）
- 与传统货运的成本对比

### 3. 什么时候盈利？（盈亏平衡）
- 单车回本周期
- 车队规模与盈利关系
- 不同场景下的盈亏平衡点

### 4. 市场有多大？（规模潜力）
- 目标市场规模
- 可替代的传统货运市场份额
- 增长潜力预测

### 5. 优势有多大？（竞争力分析）
- 成本优势（人工成本节省、运营效率提升）
- 运营优势（24小时运营、安全性、可靠性）
- 经济效益量化对比

## 快速开始

### 安装依赖
```bash
pip install -r requirements.txt
```

### 运行分析
```bash
python generate_model.py
```

生成的Excel文件位于：`output/robovan_analysis.xlsx`

## 参数配置

所有参数都在 `assumptions.json` 文件中配置，主要包括：

### Robovan参数
- 单车购置成本
- 自动驾驶系统成本
- 运营成本（能源、维护、保险）
- 服务定价

### 传统货运参数
- 车辆购置成本
- 司机工资及福利
- 运营成本（油费、维护、保险）
- 服务定价

### 市场参数
- 目标市场规模
- 市场渗透率
- 增长率

## Excel模型说明

生成的Excel包含以下工作表：

1. **参数设置** - 可视化所有假设参数，方便调整
2. **Robovan模型** - 详细的成本收入计算
3. **传统货运** - 传统模式的成本收入计算
4. **对比分析** - 两种模式的直接对比和优势量化
5. **盈亏平衡** - 回本周期和盈利规模分析
6. **市场规模** - 市场潜力和收入预测
7. **敏感性分析** - 关键参数变化的影响分析

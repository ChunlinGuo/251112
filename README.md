# Robovan商业模式分析模型 v3.0

## 项目简介

这是一个用于分析自动驾驶货运车（Robovan）商业模式的量化分析工具。通过Python代码自动生成**双视角动态Excel模型**，从运营商和厂商两个角度全面对比Robovan与传统货运方式的经济效益。

### 🎯 v3.0 核心特性

- ✅ **双视角分析**：运营商视角（买家）+ 厂商视角（卖家）
- ✅ **规模化成本模型**：研发成本分摊、远程监控规模效应
- ✅ **两种商业模式**：订阅模式 vs 一次性买断模式
- ✅ **动态公式驱动**：修改参数表，所有Sheet自动更新
- ✅ **盈亏平衡分析**：厂商需要卖多少台才能盈利
- ✅ **计算说明列**：每个关键公式都有中文解释

## 核心分析维度

### 🚚 运营商视角（购车方）

#### 1. 订阅模式 vs 人驾轻卡
- 6年TCO对比（无人车订阅模式）
- 7年TCO对比（传统人驾车辆）
- 单位成本分析（每公里/每年/每趟）
- 初始投资对比

#### 2. 核心问题
- **能省多少钱？** - 成本优势量化
- **初期投入多少？** - 现金流压力
- **长期更划算吗？** - 生命周期TCO

---

### 🏭 厂商视角（卖车方）

#### 1. 订阅模式盈利分析
- 单车成本：研发分摊 + BOM + 生产 + 销售
- 年度持续成本：监控中心 + 软件运维 + 技术支持
- 6年收入与利润：车辆销售 + 软件订阅
- **盈亏平衡台数**：需要卖多少台才能覆盖研发投入

#### 2. 规模效应
- **研发成本分摊**：`总研发 = 固定研发(3.8亿) + 边际研发(3千) × 规模`
- **监控成本**：`总监控成本 = 固定成本(500万/年) + (规模÷配比) × 安全员年薪`
- **关键洞察**：规模越大，单车成本越低

#### 3. 核心问题
- **能赚多少钱？** - 单车利润率
- **什么时候盈利？** - 盈亏平衡点
- **订阅vs买断哪个好？** - 商业模式对比

## 快速开始

### 环境准备

```bash
# 安装依赖
pip install -r requirements.txt
```

### 生成v3.0模型

```bash
# 运行v3.0生成器
python generate_model_v3.py
```

生成的Excel文件：`output/robovan_analysis_v3.xlsx` (15KB)

### 使用Excel模型

1. 打开生成的Excel文件
2. 进入 **Sheet 1: 参数配置**
3. 修改黄色单元格（可编辑参数）
4. 所有其他Sheet自动更新
5. 重点参数：
   - **销售规模**：影响研发分摊和监控成本
   - **安全员配比**：影响单车监控成本

## 核心功能演示

### 🔢 规模效应计算示例

```
销售规模：1,000台
━━━━━━━━━━━━━━━━━━━━━━━━━
总研发投入 = 3.8亿 + 3千 × 1,000 = 3.83亿
单车研发分摊 = 3.83亿 ÷ 1,000 = 38.3万/台

监控总成本 = 500万 + (1,000÷20) × 12万 = 1,100万/年
单车监控成本 = 1,100万 ÷ 1,000 = 1.1万/台/年
━━━━━━━━━━━━━━━━━━━━━━━━━

销售规模：5,000台（规模扩大5倍）
━━━━━━━━━━━━━━━━━━━━━━━━━
总研发投入 = 3.8亿 + 3千 × 5,000 = 3.95亿
单车研发分摊 = 3.95亿 ÷ 5,000 = 7.9万/台  ⬇降低79%

监控总成本 = 500万 + (5,000÷20) × 12万 = 3,500万/年
单车监控成本 = 3,500万 ÷ 5,000 = 0.7万/台/年  ⬇降低36%
```

### 📊 盈亏平衡分析示例

```
当前参数（销售规模1,000台）：
━━━━━━━━━━━━━━━━━━━━━━━━━
单车6年利润（含研发分摊）：-325,376元  ❌亏损
单车边际利润（不含研发）：+57,624元   ✓正值

盈亏平衡台数 = 3.83亿 ÷ 5.76万 ≈ 6,650台

结论：需要累计卖出6,650台车才能覆盖研发投入
```

## 常见问题

### Q: 为什么无人车生命周期只有6年？
A: 电子器件（激光雷达、传感器）老化速度快于传统机械部件，技术迭代也更快。

### Q: 如何调整参数观察规模效应？
A: 修改Sheet 1的"销售规模"和"安全员配比"，所有成本和利润会自动重新计算。

### Q: 订阅模式和买断模式哪个更好？
A:
- **运营商**：买断长期TCO更低
- **厂商**：订阅更容易盈亏平衡（4,440台 vs 25,000台）
- **结论**：市场博弈，取决于议价能力

### Q: 盈亏平衡台数如何计算？
A: `盈亏平衡台数 = 总研发投入 ÷ 单车边际利润（不含研发分摊）`
